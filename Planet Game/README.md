# Sable Reach — Planet Game

Небольшая игра о бесшовном исследовании космоса, созданная в Unity с помощью Claude Opus 5.5. В одной звёздной системе находятся три планеты: к каждой можно долететь, войти в атмосферу, приземлиться и снова взлететь без экранов загрузки.

## Самый простой запуск на Windows

1. Скачайте папку проекта через **Code → Download ZIP** и распакуйте архив.
2. Откройте папку `Planet Game`.
3. Дважды щёлкните `START_GAME.bat`.

Скрипт один раз скачает готовую версию игры из [GitHub Releases](https://github.com/Prokopiy8247/Opus5.5-4-projects/releases/tag/planet-game-v0.1.0), распакует её рядом с проектом и запустит. Unity и инструменты разработчика не нужны.

Можно также скачать `Sable-Reach-Windows-v0.1.0.zip` на странице релиза, распаковать его и запустить находящийся внутри `START_GAME.bat`.

> Сборка не подписана цифровой подписью. Windows может показать предупреждение SmartScreen; это ожидаемо для бесплатной независимой сборки. Исходный код опубликован в этой папке.

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | Тангаж и рыскание |
| `W` / `S` | Увеличить / уменьшить тягу |
| `X` | Сбросить тягу до нуля |
| `A` / `D` | Поворот влево / вправо |
| `Q` / `E` | Крен |
| `R` / `F` | Вертикальная тяга вверх / вниз |
| `Space` | Тормоз |
| `Left Shift` | Ускорение |
| `Tab` | Выбрать следующую планету |
| `J` | Импульсный двигатель |
| `L` | Помощник посадки |
| `K` | Взлёт |
| `M` | Карта системы |
| `C` | Сменить камеру |
| `F1` | Полная справка в игре |
| `Esc` | Освободить / захватить мышь |

Для первого полёта выберите планету клавишей `Tab`, направьте корабль на маркер цели, наберите скорость клавишей `W` и включите импульсный двигатель клавишей `J`. Рядом с поверхностью затормозите и используйте `L` для посадки.

## Открытие исходников в Unity

Проект использует **Unity 6000.6.0f1** и Universal Render Pipeline 17.6.0.

1. Установите Unity Hub и Unity 6000.6.0f1 с модулем Windows Build Support.
2. В Unity Hub выберите **Add project from disk** и укажите папку `Planet Game`.
3. Откройте сцену `Assets/Scenes/Game.unity` и нажмите Play.

Для сборки Windows используйте меню Unity **Tools → PG → Build Windows Player (Release)**.
